一、查询对象

查询空间 {{spaceId}} 下的对象（本体）列表，返回对象 ID、名称、apiName 及实例 / 属性 / 关系 / 行为数量。

1.1 查询对象列表 GET /meta/search?spaceId={{spaceId}}
请求参数（Query）
参数必填说明
spaceId否空间 ID，本空间固定为 {{spaceId}}
keyword否搜索关键词，匹配对象名称；不传则返回本空间全部对象
输出报文（data 为 List<OntologyMetaInfoVO>）
{
  "code": 200,
  "message": "SUCCESS",
  "data": [
    {
      "uniqueIdentifier": "3f1a2b9c-1a2b-3c4d-5e6f-7a8b9c0d1e2f",
      "displayName": "飞机",
      "apiName": "aircraft",
      "description": "航空器对象",
      "icon": "aircraft.png",
      "spaceId": {{spaceId}},
      "ontologyCategoryId": 10,
      "parentOntologyUniqueIdentifier": null,
      "parentOntologyDisplayName": null,
      "metaGroupId": ["group_001"],
      "entityCount": 128,
      "propertyCount": 15,
      "relationCount": 6,
      "actionCount": 2,
      "createTime": "2026-01-12 09:30:00",
      "updateTime": "2026-03-01 14:22:10",

curl -X GET "{{baseUrl}}/meta/search?spaceId={{spaceId}}" \

二、查询属性

按对象查询其属性（字段）列表，用于展示。

2.1 查询对象属性列表 GET /property/info?ontologyUniqueIdentifier={对象唯一标识}
请求参数（Query）
参数必填说明
ontologyUniqueIdentifier是对象唯一标识，取自 一、查询对象 返回的 uniqueIdentifier
输出报文（data 为 List<OntologyPropertyInfoVO>）
{
  "code": 200,
  "message": "SUCCESS",
  "data": [
    {
      "uniqueIdentifier": "9c0d1e2f-...",
      "ontologyUniqueIdentifier": "3f1a2b9c-1a2b-3c4d-5e6f-7a8b9c0d1e2f",
      "displayName": "名称",
      "apiName": "name",
      "description": "飞机名称",
      "propertyType": "String",
      "isPrimaryKey": false,
      "isTitleKey": true,
      "defaultValue": null,
      "storageGroup": "main",
      "categoryId": 12,
      "metadata": null
    },
    {
      "displayName": "吨位",
      "apiName": "tonnage",
      "propertyType": "Int",
      "isPrimaryKey": false,
      "isTitleKey": false,
      "storageGroup": "main"
    }
  ]
}
字段说明
字段说明
propertyType属性类型，取值：Bool / Int / Long / Float / Double / Decimal / String / Date / Timestamp / Array / Map / Vector / Geohash / Geoshape / TimeSeries / Attachment / MediaReference / Cipher / Ontology
isPrimaryKey是否主键属性（实例的唯一标识字段）
isTitleKey是否名称键属性（实例展示名所用字段）
storageGroup属性存储分组，主属性组固定为 main
调用示例（curl）
curl -X GET "{{baseUrl}}/property/info?ontologyUniqueIdentifier={对象唯一标识}" \
  -H "access-token: Bearer <token>"

三、查询关系

分页查询空间 {{spaceId}} 内的对象关系，每条关系携带两侧对象信息。

3.1 分页查询空间内关系 GET /link/list?spaceId={{spaceId}}&pageNum=1&pageSize=10
请求参数（Query）
参数必填说明
spaceId是空间 ID，本文档固定为 {{spaceId}}
relationName否关系名称模糊匹配；不传则查询本空间全部关系
pageNum否页码，默认 1
pageSize否每页条数，默认 10
输出报文（data 为 Page<OntologyLinkObjectsVO>）
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "records": [
      {
        "uniqueIdentifier": "b1c2d3e4-...",
        "name": "装备",
        "fromObject": {
          "uniqueIdentifier": "3f1a2b9c-1a2b-3c4d-5e6f-7a8b9c0d1e2f",
          "displayName": "机场",
          "apiName": "airport",
          "spaceId": {{spaceId}}
        },
        "toObject": {
          "uniqueIdentifier": "7a8b9c0d-...",
          "displayName": "飞机",
          "apiName": "aircraft",
          "spaceId": {{spaceId}}
        }
      }
    ],
    "total": 6,
    "size": 10,
    "current": 1,
    "pages": 1
  }
}
说明：uniqueIdentifier 为关系 ID（ontology_link_group.unique_identifier）；fromObject / toObject 为关系两侧对象，字段结构同 一、查询对象。
调用示例（curl）
curl -X GET "{{baseUrl}}/link/list?spaceId={{spaceId}}&pageNum=1&pageSize=10" \
  -H "access-token: Bearer <token>"

四、查询实例

分页查询对象下挂载的实例（实体）数据，返回实例主属性列表。

4.1 实例分页查询 GET /entity/list?ontologyUniqueIdentifier={对象唯一标识}&pageNum=1&pageSize=10
请求参数（Query）
参数必填说明
ontologyUniqueIdentifier是对象唯一标识，取自 一、查询对象 返回的 uniqueIdentifier
pageNum否页码，默认 1
pageSize否每页条数，默认 10
输出报文（data 为 Page<EntityInfoVO>）
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "records": [
      {
        "ontologyUniqueIdentifier": "3f1a2b9c-1a2b-3c4d-5e6f-7a8b9c0d1e2f",
        "ontologyName": "飞机",
        "primaryKey": 1001,
        "displayName": "歼-20",
        "properties": [
          { "propertyApiName": "name",    "propertyDisplayName": "名称", "propertyValue": "歼-20" },
          { "propertyApiName": "tonnage", "propertyDisplayName": "吨位", "propertyValue": 37 }
        ]
      }
    ],
    "total": 128,
    "size": 10,
    "current": 1,
    "pages": 13
  }
}
说明：primaryKey 为该对象主键属性（isPrimaryKey=true）的值，类型为 Int 或 String；后续按实例查询详情、关系时以此值作为入参。
调用示例（curl）
curl -X GET "{{baseUrl}}/entity/list?ontologyUniqueIdentifier={对象唯一标识}&pageNum=1&pageSize=10" \
  -H "access-token: Bearer <token>"
